# My Portfolio

Проста сторінка-візитка, створена в межах навчання вайб-кодингу з використанням Git, GitHub та AI-агента Cursor.

## Технології
- HTML5
- CSS3
- Git / GitHub
- Cursor AI Agent

## Як запустити
1. Клонуйте репозиторій:
   `git clone https://github.com/USERNAME/my-portfolio.git`
2. Перейдіть у папку проєкту:
   `cd my-portfolio`
3. Відкрийте файл `index.html` у браузері (подвійний клік).
